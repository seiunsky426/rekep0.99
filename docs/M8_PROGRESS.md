## 已定位的阻塞

1. **全臂地图不足**：去掉固定底座后，起点 3882 个模型体积采样点中，1044 个超出原地图边界，3532 个无观测支持（两者有重叠）。机器人最小 x 为 -0.310 m，原地图最小 x 为 -0.200 m。另有 link2 的 900/1438 点、link3 的 701/745 点投影在 RS1 彩色图像外。内部遮挡、缺深度与视野外区域不能直接当作已观测自由空间。
2. **端点环境碰撞**：5 个端点 IK 可达目标均在当前点云障碍场景中碰撞。部分接触位于底座附近黑色像素，疑似机器人点云残留；另外部分夹指碰撞对应方块周围桌面点。需要进一步修正/核验模型、机器人掩膜与场景对应，不能直接删除这些障碍。
3. **连续 IK 独立阻塞**：仅为隔离原因关闭碰撞检查时，5 条直达路径仍只完成 5.71%–8.93%；部分还出现超过 0.1 rad 的相邻关节跳变。这些结果不可执行，正式路径仍保持碰撞检查。

诊断还比较了扩大地图到 x=-0.350 m，以及使用 RS1 全部原始深度投影形成的 851×497 视图。边界越界可消除，但未知空间和净空审核仍不通过，因此没有把这份诊断地图替换为正式地图，也没有通过填洞、放宽门槛或将未知区域置为空闲来伪造通过。

下一步需要先建立足以审核全臂的 RS1 环境观测，并核验机器人自掩膜与障碍点，再重新采集、计算三个子目标和连接路径。单纯增加优化时限不能补齐这些缺失的几何证据。
